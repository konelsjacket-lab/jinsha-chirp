# 打磨计划：序章 + 第一章

> 目标：让玩家**先认识白果和朋友们，再出发**；成都拆成一块块有出入口的小地图；
> 每个角色都有自己的小故事，跟着主线一点点讲出成都的**历史、文化和神话**。
>
> 一步一步做。每一步做完给你看，你点头了再进下一步。
> 美术（第二批新角色、第二章怪物等）暂停，只做这份计划里需要的。

---

## 第 1 步 · 剧情大纲 v2（只写文档，不写代码）

**产出：** `docs/STORY.md` 重写成可以直接照着写台词的版本：
- 序章、第一章的**分场大纲**：每一场在哪、谁在场、发生什么、要讲出哪个文化点、结尾留什么钩子
- 每个角色的**小故事线**：初见 → 中段 → 揭晓，分别挂在主线的哪个节点
- **文化知识清单**：每个知识点在哪一场、由谁、用什么方式讲出来（不能像讲课，要藏在角色的事里）

**需要你拍板的点（我先给建议）：**
1. **白果的家人**：加一位**白果妈妈**。序章靠她讲出“出生那天金沙亮了一下”，睡前给白果讲蚕丛鱼凫的故事。出发时，她把一片银杏叶交给白果（第二章和银杏爷爷那条线接上）。
2. **序章要不要打架**：建议要一场教学战，对手是麻老大。好让玩家在序章里就学会战斗操作。
3. **“成都见闻录”图鉴**：每遇到一个文化点就解锁一页（比如“龟城的传说”“太阳神鸟金箔”），菜单里可以翻看。这样知识不用全挤在对话里。

### 序章「白头」草案（人民公园一张图）
| 场 | 内容 | 认识谁 / 讲什么 |
|---|---|---|
| 1 银杏树上 | 第 49 个阴天的早上。白果被麻雀帮的歌谣吵醒：“小老头，白头头……” | 白果的处境：年纪轻轻头就白了 |
| 2 窝里 | 妈妈梳毛。白果问：我的头为啥子是白的？妈妈：你出生那天，金沙那边亮了一下 | 白果妈妈；身世的钩子 |
| 3 噪噪来了 | 话痨损友拉白果去茶馆蹭瓜子（**教学：走路、对话**） | 噪噪：土画眉家老七，梦想当茶馆说书先生 |
| 4 鹤鸣茶社 | 龟大爷喝茶、讲古。“成都以前叫龟城，你们晓不晓得为啥？” | 龟大爷；**张仪筑城、神龟引路**的传说（只讲一半） |
| 5 相亲角 | 喜鹊大妈非要给白果写征婚启事 | 喜鹊大妈；成都人的松弛和热闹 |
| 6 纪念碑 | 公园里那座高高的碑，噪噪说不清是啥，龟大爷说“一百多年前，成都人为了一条铁路……” | **保路运动纪念碑**（辛亥革命的导火索），点到为止 |
| 7 麻老大 | 麻雀帮抢了小鸟们的食，白果出头（**教学战**） | 麻老大：嘴硬的对头，以后会变成朋友 |
| 8 夜里 | 梦：金色的鸟、十二道光，“来金沙找我”。醒来，妈妈坐在旁边，一夜没睡 | 主线开启 |
| 9 出发 | 妈妈给银杏叶。噪噪：“我送你到公园门口……算了我陪你走一截。” | **第一章开始** |

### 第一章「金沙之光」骨架（拆成小地图）
人民公园 → 宽窄巷子 → 金沙遗址（外围 → 祭坛）→ 锦江·合江亭 → 安顺廊桥 → 望江楼 / 杜甫草堂 / 武侯祠（三选一顺序自由）→ 锦江边石犀 → 青城山道

**每个地方的文化点（初稿）：**
| 地图 | 角色 / 小故事 | 文化点 |
|---|---|---|
| 人民公园 | 龟大爷、喜鹊大妈、麻老大、噪噪 | 龟城传说、盖碗茶和采耳、保路运动 |
| 宽窄巷子 | 戴胜师傅（采耳手艺传了好几代） | 清代**少城 / 满城**、八旗兵营变成了老街 |
| 金沙遗址 | 太阳神鸟 | **古蜀文明**、太阳神鸟金箔（2001 年出土，中国文化遗产标志）、象牙和玉琮 |
| 合江亭 / 锦江 | 鱼郎 | 两江抱城（府河、南河）、**锦官城**名字的由来（蜀锦在江里濯洗） |

| 杜甫草堂 | 杜鹃 | 杜甫在成都、“茅屋为秋风所破”；**望帝化鹃**、鳖灵治水 |
| 武侯祠 | 诸葛先生（猫头鹰） | 诸葛亮、**君臣合祀**、锦囊妙计 |
| 锦江边 | 石犀 | **李冰治水**、都江堰、石犀 2013 年在天府广场出土 |
| 熊猫基地 | 食铁兽 | 大熊猫古称、竹子 |
| 全城 | 芙蓉花 | **芙蓉城**：五代后蜀孟昶满城种芙蓉 |
| 青城山道 | （伏笔小青蛇） | 青城山、道教发源地之一 |

**角色小故事（初稿）：**
- **龟大爷**：他就是当年给张仪引路筑城的那只神龟，活了两千三百多年。序章只说“龟城”，第一章末尾揭晓。
- **噪噪**：家里七兄弟，嫌它话多。梦想当茶馆说书先生。结尾：它在鹤鸣茶社说书，讲的就是白果的故事。
- **麻老大**：小时候掉进锦江，是白果妈妈把它叼上来的。所以它嘴上骂白果，其实一直在护着白果。
- **喜鹊大妈**：每年七夕都要飞去天上搭鹊桥，是“鹊桥施工队”的老队员。
- **戴胜师傅**：师父是满城里一位八旗老兵的鸟。满城拆了，手艺留了下来。
- **鱼郎**：在合江亭等一位三年前飞走的朋友（伏笔）。
- **诸葛先生**：武侯祠里活了几百年的猫头鹰，背得出全本《出师表》，可惜每次都背到一半睡着。

## 第 2 步 · 引擎：小地图、出入口、地标

**产出：**
- 一张地图 = 一个区域。地图边缘或门口设**出口**，走过去就淡入淡出切到下一张，落在对应的入口。
- **地标物件**：大张的像素图（祭坛、牌坊、茶社……）摆在地图上，带碰撞范围、能被调查。
- 地图格式升级：地面层（现在的字符画）+ 物件列表 + 出入口列表。
- 小地图上的**区域名**和一个简单的**大地图 / 路线图**（菜单里看自己在成都的哪里）。
- 旧存档迁移：旧的大地图坐标 → 新的小地图。
- 测试：所有出口两两对得上、每张图都走得通。
