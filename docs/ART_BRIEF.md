# 美术需求（给 GPT）

把图片按**下表的文件名和尺寸**放进 `assets/img/`，刷新游戏就会自动替换掉占位图，不用改代码。
缺哪张都没关系，缺的会继续用占位图。

## 整体风格

- **像素风**，16-bit 日系 RPG 的感觉（参考《星露谷物语》《宝可梦 黑白》大地图）
- 色调：温暖但带点**阴天的灰**（成都常年不出太阳是剧情设定）；金沙相关的东西用**金色**做强调
- 所有 PNG **透明背景**（图块和战斗背景除外）
- 角色是**可爱的 Q 版**，但要认得出是什么鸟、什么动物

## 主角：白果（白头鹎）

- 黑色脑壳，**后脑勺一大撮白毛**（剧情重点，一定要显眼），耳朵位置一个小白斑
- 背和翅膀是**橄榄绿**，肚子灰白，胸口一圈淡灰褐色
- 黑色短嘴，眼睛圆亮，表情机灵带点愣
- 性格：好奇、嘴硬、有点莽
