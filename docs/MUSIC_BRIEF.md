# 音乐需求（给 Gemini）

把音频按文件名放进 `assets/audio/`（`.mp3` 或 `.ogg` 都行），刷新游戏自动生效。缺的就静音。
BGM 都会**循环播放**，首尾要能无缝接上。

## 整体方向

- 底子是 **chiptune / 16-bit 游戏音乐**，混入**四川/巴蜀元素**：
  - 川剧锣鼓、帮腔（点到为止，别太吵）
  - 竹笛、二胡、扬琴、古筝
  - 金沙/古蜀部分可以用**骨笛、陶埙、编钟**，神秘、古老、有点仪式感
- 情绪是**轻松幽默的冒险**，带一点“阴天里盼太阳”的淡淡惆怅

## BGM

| 文件 | 场景 | 时长 | 描述 |
|---|---|---|---|
| `bgm_title` | 标题画面 | 60–90 秒 | 慢起，陶埙/竹笛独奏引子，渐入温暖的旋律；阴天里透出一点金光的感觉 |
| `bgm_world` | 成都大地图 | 90–120 秒 | 轻快、悠闲，像在公园里遛弯、茶馆里摆龙门阵；竹笛主旋律 + chiptune 节奏，中速 |
| `bgm_battle` | 普通战斗 | 60 秒 | 紧张但俏皮，川剧锣鼓点 + 快速 chiptune 琶音 |
| `bgm_boss` | 石犀 Boss 战 | 60–90 秒 | 厚重、有压迫感，大鼓、低音、编钟；古老守护者的威严 |
| `bgm_sunbird` | 遇见太阳神鸟 | 60 秒 | 神圣、空灵，编钟 + 骨笛 + 合唱感的 pad，像金光慢慢亮起来 |

## 音效（短，0.1–1.5 秒）

| 文件 | 用途 |
|---|---|
| `sfx_select` | 菜单移动光标 / 对话翻页（很轻的“嘀”） |
| `sfx_confirm` | 确认选择 |
| `sfx_hit` | 攻击命中 |
| `sfx_heal` | 回血 / 获得道具 |
| `sfx_encounter` | 草丛里遇到怪（“唰”一下的紧张感） |
| `sfx_levelup` | 升级 / 学会技能（上行琶音，金光闪闪） |
