# 美术提示词包（直接复制给 GPT）

> 游戏方向：**故事为主，回合制为辅**。所以美术的优先级是：
> **白果的形象 → 对话头像（带表情）→ 剧情插图 CG → 地图 → 怪物**。

---

## 先看：怎么跟 GPT 合作

1. **先定调，再量产。** 第一张图一定是「白果设定图」。满意之后，后面所有图都在**同一个对话**里接着出，或者每次把设定图**作为参考图上传**，这样白果才不会每张长得不一样。
2. **不要让 GPT 直接出 32×32 的小图。** 它画不准小像素图。让它按默认大尺寸出（1024×1024 或 1536×1024），**原图按文件名丢进 `assets/raw/`**，缩放、抠图、切帧、调成像素风都交给 Claude 处理。
3. **背景**：角色、头像、怪物都说“透明背景”；GPT 偶尔给白底也没关系，Claude 来抠。
4. **画面里不要字。** 每个提示词结尾都带了“画面中不要出现任何文字”，GPT 写的汉字经常是错的。
5. **文件名就是 `assets/raw/` 里的名字**，比如 `portrait_baiguo_happy.png`。一张图不满意就让 GPT 重画，满意了再存。

### 风格决定（推荐）

| 用在哪 | 风格 | 为什么 |
|---|---|---|
| 对话头像、剧情 CG、标题画面 | **手绘绘本风**（柔和水彩/水粉质感，有点吉卜力味） | 故事为主，情绪全靠头像和 CG 传达；GPT 画这种风格又稳又好看 |
| 大地图（图块、行走小人） | **16-bit 像素风** | 地图要整齐、要能拼接，像素风最合适；GPT 出大图，Claude 缩成像素 |
| 战斗（怪物、背景） | 手绘绘本风 | 跟 CG 统一，战斗也像在翻故事书 |

> 像素地图 + 手绘头像/CG 是很常见的搭配，比如《八方旅人》的宣传图、很多独立 RPG 都这么做。
> 如果你想全部像素风或全部手绘，跟 Claude 说一声，提示词改一行就行。

> 小知识（可以告诉 GPT，也可以不说）：真实的白头鹎**小时候头是灰的**，长大了后脑勺才变白，所以老了叫“白头翁”。白果是**年纪轻轻就白了头**，这正是剧情的起点。
