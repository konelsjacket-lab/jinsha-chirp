# 故事设定

## 世界

成都已经连续四十九天没出太阳了。老成都人说“蜀犬吠日”，太阳一出来狗都要叫唤，可这次连狗都快忘了太阳长啥样。

真正的原因是：金沙遗址出土的**太阳神鸟**金箔上，绕着太阳飞的**四只神鸟**散落到了巴蜀各地。神鸟一走，十二道光芒也散了，成都的太阳一天比一天暗。

## 主角：白果

- 一只年轻的**白头鹎**，住在人民公园的老银杏树上（银杏是成都市树，“白果”就是银杏的果子）
- 从出生起后脑勺就有一撮白毛，别的鸟都喊它“小老头”“白老头”
- 总梦到一只金色的鸟喊它去金沙
- **动机**：想弄清楚自己为什么“少年白头”，后来知道了：出生那天，太阳神鸟用最后一点力气把一道光落在了它头上（虽然神鸟说本来是想落在凤凰头上的，准头不太好……）。于是白果出发去找回四只神鸟，让成都重新出太阳
- 招牌叫声“巧克力～巧克力～”（白头鹎的叫声在中文观鸟圈常被这么形容），是它的回血技能
