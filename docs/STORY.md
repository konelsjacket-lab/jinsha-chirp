# 故事设定（剧情圣经）

写台词前先看这里，保证前后一致。语气：**离谱但真诚**，四川话味道，笑点来自角色认真地做荒唐事。

## 世界

成都已经连续四十九天没出太阳了。老成都人说“蜀犬吠日”——太阳一出来狗都要叫唤，可这次连狗都快忘了太阳长啥样。

真正的原因：金沙遗址出土的**太阳神鸟**金箔上，绕着太阳飞的**四只神鸟**散落到了巴蜀各地。神鸟一走，十二道光芒也散了，成都的太阳一天比一天暗。

太阳神鸟本身留在金沙，只剩一缕残光，说话庄重，但准头很差、偶尔犯迷糊。

## 主角：白果

- 年轻的**白头鹎**，住人民公园的老银杏上（银杏是成都市树，“白果”就是银杏果）。性别不写死，台词里不用“他/她”。
- 真实的白头鹎小时候头是灰的，老了后脑勺才变白——**白果年纪轻轻就白了头**，被麻雀帮喊“小老头”。
- 出生那天，太阳神鸟想把一道光落在凤凰头上，**打偏了**，落在了白果头上。
- 性格：好奇、嘴硬、有点莽，心软。招牌叫声“巧克力～巧克力～”。
- 成长线：从“我只是想晓得我头上为啥是白的” → “我想让成都出太阳” → “我想让大家都好好的”。

## 章节

### 第一章 · 金沙之光（成都）
主线：做梦 → 金沙见太阳神鸟、学「神光」 → 打败石犀 → 青城山门打开，噪噪坚持同行。
支线：
- **三缺一**：龟大爷的麻将少了一张红中——它自己成精跑了。在宽窄巷子东边的草丛找到“红中”打回来。奖励：盖碗茶。
- **鱼郎的鱼竿**：锦江水猴子抢了翠鸟的鱼竿。打败水猴子头头，学「俯冲」。
- **麻老大**：在公园里嘲笑白果，打赢后服气。
- **金箔碎片**：地图上藏着金沙金箔的碎片，交给太阳神鸟，体力/气上限提升。
奇遇（走到某处触发一次）：锦鲤许愿、火锅香、武侯祠墙上的涂鸦、熊猫屁股对游客、江上漂来的求救纸条（伏笔：三星堆）、青城山道上的小青蛇（伏笔）。

### 第二章 · 青城白蛇（青城山）
1. 噪噪同行，进入青城山。山脚：腊肉、白果炖鸡招牌。
2. 石阶上山，一路雾。天师洞：银杏爷爷，名字的来历，学「银杏护体」。
3. 上清宫：鹤道长，小青怕吵。
4. 小青拦路 → Boss 战（噪噪帮腔）。小青输了哭：“我只是想让姐姐开心……”
5. 老君阁：白蛇三问（选项，没有标准答案，但真诚的回答会让她更高兴；锦囊可以拆开作弊）。
6. 阿曦现身，和白果一起回金沙。第一道光回来了。
7. 尾声：成都出了一个小时的太阳，**全城的狗都叫了起来**（蜀犬吠日）。龟大爷把茶桌搬到太阳底下。喜鹊大妈：你的征婚启事有回信了，对方是只凤凰……
→ 第三章「峨眉金顶」制作中。
