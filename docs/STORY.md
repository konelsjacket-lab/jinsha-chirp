# 金沙啾 · 剧情大纲 v2（序章 + 第一章）

写台词前先看这里。语气：**离谱但真诚**，四川话味道；笑点来自角色认真地做荒唐事，感动来自它们各自的小故事。
**故事的另一个目的：一点一点把成都的历史、文化和神话讲给玩家听。** 每个知识点都要藏在角色自己的事情里，不能像上课。

---

## 一、世界与主线

成都已经连续**四十九天**没出太阳了。老成都人说“蜀犬吠日”——太阳一出来狗都要叫，可这回连狗都快忘了太阳长啥样。

真正的原因：金沙遗址的**太阳神鸟**金箔上，绕着太阳飞的**四只神鸟**散落到了巴蜀各地。神鸟一走，十二道光散了，太阳一天比一天暗。太阳神鸟自己只剩一缕残光，守在金沙的祭坛里。

**白果**是一只年纪轻轻就白了头的白头鹎。出生那天，太阳神鸟想把最后一道光落在凤凰头上——**打偏了**，落在了白果头上。

**主线问题：** 白果想晓得“我头上为啥是白的”，后来变成“我想让成都出太阳”，最后变成“我想让大家都好好的”。

## 二、角色与他们的小故事

每个角色都有一条**初见 → 中段 → 揭晓**的小故事线，挂在主线的不同节点上。

### 白果（主角，白头鹎）
- 住在人民公园最老那棵银杏树上。银杏是成都市树，“白果”就是银杏的种子。
- 真实的白头鹎小时候头是灰的，老了后脑勺才变白，所以被喊“白头翁”。白果**一岁就白了头**，被麻雀帮编歌谣笑话。
- 好奇、嘴硬、有点莽，心软。招牌叫声“巧克力～巧克力～”（白头鹎的叫声在中文观鸟圈常被这么形容）。
- 台词里不写死性别，不用“他 / 她”。

### 白果妈妈（新角色，白头鹎）
- 后脑勺的白毛是正常长出来的，“老了才白，这才对嘛”。温柔、爱操心、讲故事很好听。
- **初见（序章）**：给白果梳毛，讲出生那天“金沙亮了一下”；睡前讲**蚕丛和鱼凫**的故事：古蜀最早的王，蚕丛教大家养蚕，眼睛长得凸凸的，往前看得好远。（伏笔：三星堆的纵目面具 → 第四章）
- **中段（第一章中途回公园）**：白果发现妈妈每天都飞到公园门口，望着西边。
- **揭晓（第一章结尾）**：一年前，麻老大还是小麻雀，掉进锦江，是妈妈冒着雨把它叼上来的，自己的翅膀从此飞不远了。所以她不能陪白果去，只能送一片银杏叶：“白果落在哪里，就在哪里长成树。”（接第二章银杏爷爷）

### 噪噪（白果的损友，白颊噪鹛 / 土画眉）
- 土画眉一家七兄弟，它排老七。哥哥们都嫌它话多。
- **梦想当茶馆的说书先生**。每次在鹤鸣茶社听评书都听得最认真，回去学给白果听，学得一塌糊涂。
- **初见（序章）**：拉白果去茶馆蹭瓜子；全程叭叭叭当导游，讲错一半。
- **中段**：一路上给白果“说书”，把刚发生的事添油加醋讲一遍（玩家按“互动”就能听到）。
- **揭晓（第一章结尾）**：“我也要去。等我们回来，我要在鹤鸣茶社说一回书——就讲你。”
- 战斗中帮腔：叭叭叭把敌人吵烦（降防御）、喊加油（回血）、偶尔啄一口。

### 龟大爷（鹤鸣茶社的老乌龟）
- 在鹤鸣茶社喝了“一百多年”茶，口头禅“莫急”。回血、存档点。
- **初见（序章）**：“成都以前叫**龟城**，你们晓不晓得为啥子？”讲了一半就打瞌睡了。
- **中段**：三缺一（红中跑了）；讲**盖碗茶**为啥有盖有碗有托（天地人）；讲老成都的**采耳**。
- **揭晓（第一章结尾）**：两千三百多年前，秦国的张仪在这里筑城，城墙修了好几回都塌了。有一只大龟在地上慢慢爬了一圈，人们照着龟爬的路线筑墙，城才立住——那只龟就是龟大爷。“这座城的第一圈城墙，是我爬出来的。”（出自《华阳国志》《搜神记》的“龟城”传说）

### 喜鹊大妈（相亲角）
- 人民公园相亲角的头号热心人，非要给白果写征婚启事。
- **中段**：七夕快到了，她要去“上班”——她是**天上鹊桥施工队**的老队员，牛郎织女相会那天，全天下的喜鹊都要去搭桥。
- **揭晓（第二章尾）**：征婚启事有回信了，对方是一只凤凰（太阳神鸟当年本来要照的那只）。

### 麻老大（麻雀帮老大）
- 序章的对头，带着麻雀帮编歌谣笑白果，抢小鸟的食。序章教学战的对手。
- **中段（第一章锦江边）**：白果被水猴子拖向江心，麻老大冲出来把白果拽回岸上，嘴上骂骂咧咧。
- **揭晓**：一年前它掉进锦江，是白果妈妈救的。“我欠你家一条命。……但是你头发白，我还是要笑。”

### 戴胜师傅（宽窄巷子的采耳师傅）
- 想给鸟采耳，研究了一晚上才找到鸟的耳朵在哪儿。
- **小故事**：它的师父，是清朝**满城**里一位八旗老兵养的鸟。三百年前，这里叫**少城**，是八旗兵驻扎的城中之城，一条条胡同就是兵营。城墙拆了，胡同留下来，变成了宽巷子、窄巷子、井巷子；手艺也留下来，一代传一代。

### 鱼郎（翠鸟，合江亭钓鱼佬）
- 钓了三年鱼，一条都没钓到过。鱼竿被水猴子抢了（支线）。教白果「俯冲」。
- **小故事**：它在等一个三年前从合江亭飞走的朋友。两条江在这里汇合，它说“走散的，总会在下游碰到”。讲**两江抱城**（府河、南河）和**锦官城**——古时候织好的蜀锦拿到江里洗，颜色格外鲜亮，管织锦的官叫“锦官”，这座城就叫锦官城，这条江就叫锦江。

### 竹婆婆（新角色，望江楼的老竹子精）
- 望江楼公园里种着上百种竹子，竹婆婆是里头最老的一丛。说话慢，爱念诗。
- **小故事**：一千二百年前，有一位女诗人**薛涛**住在浣花溪边，自己染了一种小小的桃红色信笺来写诗，人称**薛涛笺**。竹婆婆说，那时候它还是一根小竹笋，薛涛在它旁边写过诗。
- 主线：给白果一张薛涛笺，让白果给石犀写一封信。

### 杜鹃（杜甫草堂，望帝所化）
- “不如归去～不如归去～”
- **小故事**：它是古蜀的**望帝杜宇**。他教百姓种地；蜀地发大水，一个叫**鳖灵**的人凿开山把水引走，望帝把王位让给了他（鳖灵就是开明帝）。望帝死后化成杜鹃，每年春天啼叫，叫到嘴里出血，染红了杜鹃花——“望帝春心托杜鹃”。
- 也讲**杜甫**：一千两百多年前，杜甫逃难到成都，在浣花溪边搭了座茅屋，住了快四年，写了两百多首诗。一阵秋风把屋顶的茅草全卷跑了，他写了《茅屋为秋风所破歌》，想的却是“安得广厦千万间，大庇天下寒士俱欢颜”。还有那句写成都夜雨的“**好雨知时节，当春乃发生**”。

### 诸葛先生（武侯祠的猫头鹰）
- 摇羽扇的算命先生，送白果锦囊，然后想收五十块。
- **小故事**：它在武侯祠住了几百年，最崇拜诸葛亮，能背全本《出师表》——可惜每次都背到“鞠躬尽瘁”就睡着了（猫头鹰白天要睡觉）。
- 讲**武侯祠**：全国唯一一座**君臣合祀**的祠庙，刘备的墓（惠陵）和诸葛亮的祠堂在一起；杜甫写过“丞相祠堂何处寻，锦官城外柏森森”。
- 主线：考白果三个问题（复习前面学到的东西），答对了才给锦囊。

### 太阳神鸟（金沙祭坛）
- 庄重，但准头很差、偶尔犯迷糊。
- 讲**古蜀文明**：三千年前，古蜀人在金沙一带生活、祭祀，留下了象牙、玉琮、金器。**太阳神鸟金箔**2001 年在金沙出土，薄得像纸，十二道光芒旋转，四只神鸟绕着太阳飞。现在它是**中国文化遗产标志**。

### 石犀（锦江边，第一章 Boss）
- 严厉、沉默，守城两千多年。
- 讲**李冰治水**：两千多年前，秦国蜀郡太守**李冰**修了**都江堰**，从此成都平原“水旱从人”，变成天府之国。他还做了五头石犀放在水边镇水。**2013 年，一头石犀在成都天府广场工地被挖了出来**——它就是其中一头。

### 食铁兽（熊猫基地，可选）
- 古时候的人喊大熊猫“食铁兽”“貘”，传说它会啃铁锅。“其实我们只吃竹子……偶尔吃个苹果。”
- 送钵钵鸡（白果：？）。

### 芙蓉花精（新角色，全城各处的芙蓉树）
- 小奇遇角色。讲**芙蓉城**：一千多年前后蜀的皇帝孟昶，在成都城墙上种满了木芙蓉，秋天一开，整座城像铺了锦，所以成都也叫“蓉城”。
